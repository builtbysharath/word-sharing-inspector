## 0.1.1 imported-content regression

A fictional DOCX with a `w:altChunk` element, a standard `/aFChunk` relationship, and a `text/html` payload outside `word/embeddings/` reproduced a missed finding in 0.1.0. The new regression failed before the fix and passes afterward. The inspector now reports that the imported target needs separate inspection; it does not parse or render the HTML payload. Both alternate-format relationship URI forms, embedding deduplication and external references have regression coverage. The rebuilt browser worker uses the same corrected inspection core. The corpus is fictional and native Word rendering remains unverified.

The 0.1.1 suite passes all 42 tests on Node 22.23.3 and the development Node 23.10.0 runtime. The rebuilt local browser reports one imported-content finding for `examples/imported-content.docx`; the sample still reports nine findings and filtering shows the expected two tracked changes. The standalone browser ZIP launcher was exercised on Node 22: HTML and worker GET requests succeeded, POST was refused, and the connection-blocking CSP was present.

## Hosted worker policy after 0.1.1

GitHub Pages does not send the local server's CSP response header for `worker.js`. The browser now starts an embedded blob worker, which [inherits the document's CSP](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers#content_security_policy). The page permits only blob workers and keeps `connect-src 'none'`. A separate local browser probe using the actual compiled worker plus a synthetic fetch attempt showed `Worker fetch: BLOCKED` and one imported-content finding under the same meta CSP, without relying on response headers. The rebuilt app still returned nine sample findings. A controller regression verifies termination and URL release on Clear; the hosted-policy baseline had 43 passing tests. The probe is local verification material, outside the published static assets. This is a tested browser policy boundary, not a comprehensive security audit or native Office rendering check.
