A Word file can carry saved comments, deleted text, reviewer identities and metadata beyond the text in the current view.

Why a Word document inspector for Mac?

Microsoft documents that Word for Mac has no built-in Document Inspector. Word Sharing Inspector gives Mac users a browser-based way to review selected details saved in a DOCX before sharing it.

No installation is required. The browser app is also available to other desktop users. Review each finding in Word; this tool does not remove content or perform every check in Microsoft's Windows inspector.

What can this inspector show?

Saved comments and tracked changes, direct hidden-text formatting, selected author and custom properties, imported-content references, external links and selected extra package data.

Use the suggested review actions in Word. Imported or embedded payloads need separate inspection. This tool reports findings and never rewrites your document.

What does “no findings” mean?

Only that the performed checks returned no findings. Images, embedded-file internals, cloud history, visual overlays, all inherited styles and unsupported content remain outside this inspection. It is not a privacy or malware certificate, a rendered Word preview or a document cleaner.

Only ordinary macro-free .docx files up to 25 MB are supported. Native Word/LibreOffice rendering has not been tested.

Where does my file go?

Your selected document is read and inspected in your browser. The app has no document-upload endpoint, analytics or model API, and its Content Security Policy blocks outbound connections. GitHub Pages serves the static app and may log website visits; it does not receive your document through this inspector.

Saved JSON reports can contain names and excerpts. Review them before sharing. Use fictional data or a sanitized report for feedback.
